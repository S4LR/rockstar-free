# rockstar-free
Free open-source Hacked client for Minecraft 1.12.2

Cheat for playing on ReallyWorld, SunRise, and other servers, as well as suitable for playing on 1.8

## 🔨 Building from Source

### Requirements
- Java JDK 8
- Git

### Build Instructions

1. **Clone the repository**
```bash
git clone https://github.com/yourusername/rockstar-free.git
cd rockstar-free
```

2. **Build the project**
```bash
./gradlew build
```
On Windows, use:
```bash
gradlew.bat build
```

3. **Find the compiled JAR**
The built JAR file will be in `build/libs/rockstar-free-1.0.jar`

### GitHub Actions
This project includes automatic builds via GitHub Actions. Every push to main/master branch will automatically build the project and create artifacts.

## 📥 How to Install

1. Download the compiled JAR from the releases or build it yourself
2. Place it in the versions folder in your minecraft folder
3. Select Rockstar Free version and run
